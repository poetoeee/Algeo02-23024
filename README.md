# Algeo02-23024
Proyek ini bertujuan untuk membuat aplikasi yang dapat mencari kemiripan antara lagu dan gambar dengan sebuah dataset.


- **Frontend**: Next.js
- **Backend**: Python
- 
- **Libraries**:
  - `Flask`: API.
  - `mido`: Pemrosesan midi.
  - `NumPy`: Perhitungan matematika.
  - `Matplotlib`: Visualisasi Data.
  - `Pillow`
  - `scipy`

## Setup and Installation

1. **Clone Repositori**:
   ```bash
   git clone https://github.com/poetoeee/Algeo02-23024.git
   cd Algeo02-23024
   ```

2. **Install Dependencies**:
   
   ```bash
   pip install -r requirements.txt
   ```
  

4. **Run the Application**:
   - Backend:
     ```bash
     python src/backend/server.py
     ```
   - Frontend:
     ```bash
     cd frontend
     npm run dev
     ```


**Input Files**:
 - Untuk fitur lagu, unggah file midi untuk dataset atau query
 - Untuk fitur gambar, unggah file jpg, jpeg, dan png untuk dataset atau query
